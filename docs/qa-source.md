## 4. お客様の声から見えた「聞かれそうな質問」

アンケート（181件・2025/11〜2026/10）と夜間営業報告から、QAとして先回りしたい論点。個人を特定できる記述は含めていない。

1. **ペットと入れるか** … 同伴来店が約4人に1人。最重要のQA
2. **待ち時間・混雑** … 改善要望に「待ち時間」。混雑する時間帯の案内があると有効
3. **座席の種類** … 畳席・テーブル席の希望が分かれる。掘りごたつ要望あり
4. **夜の看板が見つけにくい** … 夜営業の来店時のアクセス案内に一言添えると有効
5. **取り皿** … シェア前提の来店が多い（2人来店 61.3%）
